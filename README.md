## 🚀 Featured Project — **Renova**

> **Role:** Project Manager + Full-Stack Developer  

**Renova** is a smart recycling ecosystem combining:

- **IoT:** Sensor-based smart container  
- **AI:** Material classification powered by prompt-based workflows and automation through **n8n**  
- **Mobile App:** Kotlin + Firebase Cloud Messaging (FCM)  
- **Backend:** Django + .NET  
- **Dashboard:** Web admin panel for control, metrics & operations  

### My Contributions:
- Planned and executed the full project roadmap  
- Designed UX flows for the mobile app, admin dashboard, and hardware interface  
- Developed Android functionality (Kotlin + FCM notifications)  
- Built backend APIs and coordinated hardware–software integration  
- Conducted usability testing and iterative UX improvements
